# Contributing to MINO

Thank you for your interest in contributing to MINO — Deepfake Detection & Media Forensics Platform.

## Code of Conduct & Forensic Integrity
1. MINO is designed as a transparent, probabilistic forensics tool. Never falsify benchmark metrics, detector capabilities, or accuracy claims.
2. Ensure any new model backbone or training dataset strictly complies with its originating license and usage guidelines.
3. Keep user-uploaded media and test datasets strictly out of source control.

## Development Workflow
- Follow Conventional Commits: `feat:`, `fix:`, `chore:`, `docs:`, `test:`, `refactor:`, `security:`.
- Ensure all automated unit and integration tests pass before opening a Pull Request.
- Follow the PEP 8 standard for Python code and ESLint/Prettier for TypeScript code.
